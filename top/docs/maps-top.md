# MAPS Top

`maps-top` is a terminal-oriented live operational view of a MAPS Messaging server. It provides a compact view of server statistics for operators and developers without requiring a browser-based administration interface.

## Installation

Install the `maps-apps` Debian package. The package installs `maps-top` and its section 1 manual page.

```bash
man maps-top
```

## Use

Run `maps-top` with the connection and authentication options described by `maps-top --help` and the installed manual page. The display is intended for interactive terminal use and can be used during development, field testing and operational diagnosis.
